# Esqueleto — Landing Page

Esta é a base obrigatória do projeto.

Ela contém:

- Menu
- Hero
- O Problema e a Dor
- Prova Social / Conquistas
- Oferta e Condições
- FAQ
- Chamada Final
- Rodapé

A estrutura é propositalmente simples.

A ideia é que cada aluno adapte:

- textos
- cores
- fontes
- imagens
- espaçamentos
- componentes
- interações
- conteúdo

Abra `index.html` no navegador para visualizar.
