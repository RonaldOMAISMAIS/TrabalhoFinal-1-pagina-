# Etapas do projeto

## Etapa 1 — Planejamento
Defina tema, público, objetivo e conteúdo.

## Etapa 2 — Protótipo
Monte a organização visual antes de programar.

## Etapa 3 — Estrutura
Use HTML semântico para montar as seções.

## Etapa 4 — Estilização
Defina cores, tipografia, espaçamento e identidade visual.

## Etapa 5 — Interações
Use JavaScript quando uma interação fizer sentido.

## Etapa 6 — Responsividade
Teste a página em diferentes larguras.

## Etapa 7 — Integração
Quando solicitado, conecte a uma API.

## Etapa 8 — Performance
Use boas práticas e teste com Lighthouse.

## Etapa 9 — GitHub
Mantenha commits organizados e o repositório atualizado.

## Etapa 10 — Entrega
Revise o checklist e publique a versão final.
