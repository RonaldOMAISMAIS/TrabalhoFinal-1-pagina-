# Como usar os componentes

Cada pasta da biblioteca contém um exemplo independente.

Normalmente você encontrará:

- `index.html` — estrutura
- `style.css` — estilos
- `script.js` — interação, quando necessária
- `README.md` — explicação

## Para adaptar

1. Abra o exemplo.
2. Entenda a estrutura.
3. Copie somente o que precisa.
4. Cole no seu projeto.
5. Altere nomes de classes se necessário.
6. Troque textos, cores, imagens e conteúdo.
7. Teste novamente.

Não é necessário usar todos os componentes.
