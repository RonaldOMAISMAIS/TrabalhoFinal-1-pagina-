# Projeto Final — Front-End

Bem-vindo ao projeto final!

Você receberá uma estrutura simples de Landing Page para usar como ponto de partida.
A ideia NÃO é copiar o modelo e trocar os textos. Use a estrutura para construir uma
página própria, com identidade visual, conteúdo, imagens e decisões de interface do seu projeto.

## Ordem sugerida

1. Escolha o tema/projeto.
2. Crie o protótipo.
3. Crie/organize o repositório no GitHub.
4. Adapte o esqueleto da Landing Page.
5. Personalize cada seção.
6. Consulte a biblioteca de componentes quando quiser trocar algum elemento.
7. Adicione interações com JavaScript.
8. Torne a página responsiva.
9. Faça uma integração com API quando solicitado.
10. Teste a performance e o funcionamento.
11. Organize o GitHub e faça a entrega final.

## Seções obrigatórias

- Link GitHub
- Protótipo
- Menu
- Hero
- O Problema e a Dor
- Prova Social (depoimentos) ou conquistas
- Oferta e Condições
- FAQ
- Rodapé e Chamada Final

## Regra principal

O material é uma biblioteca de consulta. Você pode adaptar, combinar e modificar os exemplos.
O resultado final deve representar o seu projeto.
