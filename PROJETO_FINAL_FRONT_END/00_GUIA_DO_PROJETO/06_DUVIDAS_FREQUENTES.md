# Dúvidas frequentes

## Posso mudar a estrutura?
Sim. O esqueleto é uma base.

## Preciso usar todos os componentes?
Não.

## Posso misturar componentes?
Sim. Adapte os exemplos para o seu projeto.

## Posso mudar as cores?
Sim. A identidade visual é parte do projeto.

## Posso mudar as seções?
As seções obrigatórias precisam existir, mas você pode acrescentar outras.

## Posso usar JavaScript?
Sim. Use quando ele realmente contribuir para a experiência.

## Preciso usar uma API?
Siga o que for definido para a etapa da turma. A biblioteca contém exemplos para consulta.
