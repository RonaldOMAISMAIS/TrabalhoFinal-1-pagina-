# Critérios de entrega

A entrega deve apresentar:

1. Uma Landing Page funcional.
2. Todas as seções obrigatórias.
3. Identidade visual própria.
4. Layout responsivo.
5. Interações previstas no projeto funcionando.
6. Código organizado.
7. Repositório no GitHub.
8. README explicando o projeto.
9. Testes finais realizados.
10. Link final funcionando.
